3. CONVENZIONE DEL MODELLO
-------------------------

Coordinate link: q = [q1; q2]
Coordinate rotori: theta = [theta1; theta2]
Deformazione SEA: delta = theta - q
Ingresso: tau = [tau1; tau2], coppia motore in N*m

Convenzione unica dello stato, registrata come decisione D-0002:

x = [q; qdot; theta; thetadot]
  = [q1, q2, q1dot, q2dot, theta1, theta2,
     theta1dot, theta2dot]^T

La funzione principale restituisce xdot nello stesso ordine.

5. EQUAZIONI IMPLEMENTATE
-------------------------

M(q) qddot + C(q,qdot) qdot + G(q) = Ks(theta-q)
Jm theta_ddot + Bm theta_dot = tau - Ks(theta-q)

M11 = (m1+m2)l1^2 + m2*l2^2 + 2*m2*l1*l2*cos(q2)
M12 = M21 = m2*l2^2 + m2*l1*l2*cos(q2)
M22 = m2*l2^2

Ponendo h = m2*l1*l2*sin(q2):

C = [-h*q2dot, -h*(q1dot+q2dot);
      h*q1dot,  0]

G1 = (m1+m2)g*l1*cos(q1) + m2*g*l2*cos(q1+q2)
G2 = m2*g*l2*cos(q1+q2)

tau_el = Ks(theta-q)
qddot = M \ (tau_el - C*qdot - G)
theta_ddot = Jm \ (tau - Bm*theta_dot - tau_el)

È stata usata la soluzione di sistemi lineari MATLAB, mai inv(M).

9. POSITIVITÀ ANALITICA DI M
----------------------------

Il campionamento non è stato chiamato prova globale. È stata documentata
separatamente la derivazione:

m11 >= m1*l1^2 + m2*(l1-l2)^2 > 0

det(M) = m2*l1^2*l2^2*(m1 + m2*sin(q2)^2) > 0

Per il criterio di Sylvester, M(q) è definita positiva per ogni q2 con i
parametri fisici positivi. Il campionamento verifica che il codice rispetti
la proprietà sul dominio numerico richiesto.
