M(q) qddot + C(q,qdot) qdot + G(q) = Ks(theta-q) + d.

d = [d1; d2] e' una coppia esterna ai link in N m.

Per lo stato meccanico [q; qdot; theta; thetadot]:

Bd = [
   0          0
   0          0
   6.25     -14.5833333
 -14.5833333  47.9166667
   0          0
   0          0
   0          0
   0          0
].

Il blocco non nullo e' M(qbar)^-1 nelle accelerazioni link.

- differenza finita centrata del modello non lineare con disturbo;

8. PESO W1
======================================================================

Formula:

W1(s) = (s/Ms + omegaB) / (s + omegaB As).

Griglia:

- As = 0.03, 0.05, 0.08;
- Ms = 1.7, 2.0, 2.4.

Regola: preferire deterministicamente la severita' mediana su As e Ms.

Baseline:

- omegaB = 12 rad/s;
- As = 0.05;
- Ms = 2.0;
- W1(0) = 20;
- W1(infinito) = 0.5;
- stabile, proprio, ordine SISO 1.

Interpretazione:

- sensitivity a bassa frequenza target dell'ordine del 5 percento;
- picco desiderato dell'ordine di 6 dB;
- target non ancora dichiarato fattibile o soddisfatto.

9. SCALA DI SFORZO E PESO W2
======================================================================

uScale analizzati: 8, 12 e 16 N m.

Baseline: uScale = 12 N m, valore mediano.

uScale e' un parametro di normalizzazione/prestazione e NON una
saturazione certificata dell'attuatore.

Formula:

W2(s) = (1/uScale) (s/omegaU + 1) /
        (s/(alpha omegaU) + 1).

Griglia:

- omegaU = 25, 30, 35 rad/s;
- alpha = 4, 6.

Ammissibilita' e ranking:

- onset inferiore alla banda attuatore;
- onset non oltre meta' del primo modo elastico;
- preferenza per uScale mediano;
- omegaU ammissibile piu' vicino dal basso alla banda attuatore;
- alpha maggiore come tie-break dinamico.

Baseline:

- omegaU = 30 rad/s;
- alpha = 6;
- distanza banda attuatore = 4.78337 rad/s;
- distanza primo modo elastico = 39.9543 rad/s;
- W2(0) = 1/12 = 0.0833333 (N m)^-1;
- W2(infinito) = 6/12 = 0.5 (N m)^-1;
- stabile, proprio, ordine SISO 1.

W1 e W2 MIMO sono diagonali 2x2 con pesi identici sui due giunti.
W3 non e' stato introdotto.
