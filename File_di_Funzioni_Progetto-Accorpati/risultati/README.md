# Evidenze correnti e risultati storici

La configurazione corrente del 4 novembre 2026 è identificata dalla firma versione 3 in parametri_sea.m: m2=0.8 kg ±10%, quattro reali attuativi, zeta noto. I CSV/MAT caricati da run_all sono controllati contro questa firma; gli esiti precedenti non vengono trasferiti.

File con carico nel nome, esecuzione_completa.txt e vecchi audit senza la data 20261104 sono cronologia: non costituiscono evidenza della configurazione corrente. Il loro contenuto resta consultabile senza essere incluso nella consegna attuale.
